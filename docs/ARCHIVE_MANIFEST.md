## 3. The gates, and the remaining gap (documented, not closed)

Two standards governed every phase and remain in force:

- **Development gate: 0.96** — on the fixed validation AND both independent
  cross-checks (models A and B, trained on disjoint splits), all four
  holdouts (random, site, period, long) reported separately.
- **Submission standard: ≈0.998 under genuinely independent validation** —
  the standard a candidate file would have to meet before a submission slot
  could be proposed. (Context: the public board's top score is 0.994250562;
  the corrected construction's own oracle ceiling measures 0.9981–0.9983.)

## 4. Common protocol (Phases 5–8B, frozen from Phase 5 onward)

Unless a phase states otherwise, every model from Phase 5 onward shares:
LightGBM with parameters `{objective: regression, metric: rmse,
learning_rate: 0.05, num_leaves: 63, min_data_in_leaf: 40,
feature_fraction: 0.85, bagging_fraction: 0.85, bagging_freq: 1,
lambda_l2: 1.0, seed: 20261116}`, 6,000-round cap, early-stopping patience
200 on an internal 90/10 split; training sets main 80,000 / A 40,000 /
B 40,000 windows (A and B disjoint in both background windows and passage
clips — the independent cross-check); holdouts of 6,000 windows each
(random; site = Bird Island + Fish Hoek held out; period = latest 15% of
periods; long = forced long events); 549 fixed per-window features (605
with family D); score = 1 − RMSE on `share_added_vessel`;
`score_added_vessel = sqrt(share)` as the fixed zero-weight companion.
Software: python 3.12.3, numpy 2.5.5, pandas 3.1.1, scipy 1.18.1,
lightgbm 4.7.0, scikit-learn 1.9.1 (harvest additionally: pyarrow 26.0.1,
soundfile 0.14.0). Master seed **20261116** everywhere unless a phase
records its own stream seed below.
